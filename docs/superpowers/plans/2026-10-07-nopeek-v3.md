# Nopeek v3 45s Launch Film Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `nopeek-film/film3.html` 45s deterministic launch film + soft synth score + QA gates.

**Architecture:** Single `seek(t)` canvas film reusing v1/v2 pipeline (lib/render/encode/sheet/phone/still/selftest). Six acts share one spine object via morph/flood handoffs, camera one-move-at-a-time in log space.

**Tech Stack:** Vanilla HTML/Canvas JS (no deps), Playwright Chromium screenshots, ffmpeg-static encode, Node synth audio, Big Shoulders + Schibsted via document.fonts.load.

**Spec:** `docs/superpowers/specs/2026-10-07-nopeek-v3-design.md` (plus `nopeek-film/docs/storyboard_v2.md`, `style_guide.md`, `motion_spec.md` for values)

## Global Constraints

- FPS 60, DUR 45.000s, TOTAL 2700 frames — `tools/lib.mjs` and `film3.html` must match.
- Pure function of t: no timers, no rAF, no CSS transitions, no Math.random (seeded only), no globalAlpha fades.
- Palette pitch #10261B chalk #F1F0E6 volt #D4FF00 sky #8FD3FF coral #FF6A4D only; volt=you sky=opponent.
- Type Big Shoulders 900 statements / Schibsted UI only; max 6 words per statement.
- Copy locked: RESOLUTIONS ARE FREE. / SO IS BREAKING THEM. / So put $5 on it. / This is a duel. / The phone counts. / The money settles itself. / NOPEEK / Get Nopeek now. / Android first · Test stakes today.
- Fidelity to CreateScreen.kt / DuelScreen.kt / Cards.kt / WonScreen.kt / HomeScreen.kt; only deviations tape limit 82% + volt underline spine.
- Sound synth-only, -18.1 LUFS / -2.4 dBTP target, ~22 cues, duck -4dB under type.
- selftest.mjs 24/24 PASS required before encode.

## Review Focus

- Long statement unreadable at 800x450 phone size — expect full sentence legible without pause.
- Tape limit misplaced at 1.0 instead of 0.82 — expect visible headroom past limit for breach.
- Flood fails to cover farthest corner — expect full-frame volt/coral with no sliver.
- Type springs/bounces — expect appEase only on type, springs on markers/cursor only.
- End CTA held <3s — expect 5.0s hold readable + screenshotable.
